Pop-up M5 “Add or edit Custom Item” — Diabetes Companion SA

Purpose: Accessible bottom sheet modal sliding up over dimmed Screen S9 “Daily Checklist” on a 360 px wide phone. Enables authenticated users to add or edit custom personal checklist routine items (capped at 6 own items). Formatted strictly with 16 px screen gutters, 48 px high interactive controls, character validation (1–60 chars), duplicate detection, and post-success toast feedback on Screen S9.

Part 2 • Post-Success Destination: Screen S9 "Daily Checklist" with Toast "Item saved."

Modal Dismissal & Checklist Toast Flow

As required by the clinical design system: no success state is shown inside the bottom sheet itself.

  • Upon tapping Save with a valid custom item name, the bottom sheet modal closes immediately.
  • The user returns to Screen S9 “Daily Checklist”.
  • The new personal care item (e.g., “Evening walk”) is appended to the Personal routine items section with interactive checkbox, Edit link, and Delete link.
  • A high-contrast dark toast notification appears fixed above the bottom tab bar with the exact copy: “Item saved.”
  • The checklist progress indicator smoothly updates to reflect the updated active routine count (e.g., 2 of 5 done, or 4 of 6 done).
