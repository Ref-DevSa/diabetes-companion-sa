Pop-up M1 “Add or edit Reading” — Diabetes Companion SA

Purpose: Bottom sheet that slides up over Screen S8 “Glucose Diary” to log or edit blood sugar readings. The background screen is dimmed. Only logged-in users access it. Formatted strictly for a 360 px wide phone with 16 px screen side padding, 48 px high form controls, 44×44 px minimum tap targets, full field validation states, character counter, and authentic operational feedback.

State 1: Normal (Add Mode - Empty Defaults) State 2: Normal (Edit Mode - Sample 6.8 mmol/L) State 3: Loading ("Saving..." Disabled) State 4: Field Validation Errors State 5: Rate Limit (30 readings/day) State 6: Conflict ("No longer exists") State 7: Offline State State 8: Success - Standard Toast State 9: Success - Clinical Flag Toast
