4. Accessibility & Rule Conformance Matrix

Strict Rule Compliance Audited
  • Values Only: Strict adherence to provided HEX palette, dimensions, and Inter typography.
  • No Color Alone: Flags, errors, and badges all incorporate Lucide outline icons and explicit text words.
  • Contrast Ratio: Primary blue #1A6BD1 white text is 5.16:1 (passes > 4.5:1). Dark blue headings are 7:1+.
  • Touch Target Size: Every tappable element is at least 44 × 44 px (buttons are 48 px high).
  • Surfaces: Flags, errors, and success text strictly sit on white card surfaces (#FFFFFF).
  • Imagery: No photos of people, no profile pictures. Flat, simple vector icons and illustrations only.
Responsive Breakpoints Fluid Architecture
Phone (< 640 px): Single column layout with 16 px screen margin, fixed 56 px bottom tab bar, and header hiding wordmark below 400 px.
Tablet (640 to 1024 px): One centered column capped at 720 px max width, bottom tab bar transitions to a top navigation bar.
Desktop (> 1024 px): Top navigation bar with content comfortably scaling up to 1200 px max width.
