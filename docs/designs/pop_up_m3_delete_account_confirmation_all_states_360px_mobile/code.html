POST-SUCCESS DESTINATION: HOME SCREEN S1 WITH CONFIRMATION TOAST

Success Behavior Spec

Redirect to Home & Clean Session Termination

As specified, no success state is shown inside the pop-up modal.

Upon successful deletion:

  • The pop-up closes and authenticated session tokens are immediately revoked.
  • The user is redirected to Screen S1 (Home) in logged-out unauthenticated state.
  • A high-contrast dark toast appears above the bottom bar with the exact copy: “Your account and data have been deleted.”
  • The header switches back to unauthenticated controls (Log in / Sign up) and the bottom tab bar reflects guest access.

POPIA & Clinical Guardrails Compliance Verification

Strict Form Factor & Dimensional Safety

Dialog box width is capped at 328 px, allowing 16 px margin on standard 360 px viewports. 48 px high interactive controls satisfy strict motor accessibility guidelines.

Irreversible Data Erasure Notice

Verbatim POPIA disclosure explicitly cautions the user that personal accounts, glucose diary readings, and daily checklist care logs cannot be recovered.

Robust Network Resilience

Prevents state desynchronization with explicit connectivity checks and offline warnings, ensuring deletion requests only execute under verified connectivity.
