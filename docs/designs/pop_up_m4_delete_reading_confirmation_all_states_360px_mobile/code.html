Pop-up M4 “Delete Reading confirmation” — Diabetes Companion SA

Purpose: Provide an explicit, high-contrast confirmation pop-up (centred dialog, up to 328 px wide on a 360 px viewport) before permanently deleting an existing blood glucose record. Only logged-in users see it. Displays over the dimmed Screen S8 “Glucose Diary”. Followed by deletion and navigation back to Glucose Diary showing the toast notification “Reading deleted.”

Post-Success Destination: Glucose Diary with Confirmation Toast

Success Behavior Spec

As specified: no success state is shown inside the pop-up modal.

  • The pop-up modal closes immediately upon API deletion confirmation.
  • The user remains on or is returned to Screen S8 (Glucose Diary).
  • The deleted record (3.6 mmol/L Bedtime) is permanently removed from the diary list.
  • A dark high-contrast toast notification appears fixed above the bottom tab bar with the exact copy: “Reading deleted.”
Design Consistency Notes

• Modal width constraint: strictly capped at 328 px wide, leaving 16 px screen margins on standard 360 px width Android phones.

• Button height: 48 px high for both destructive and secondary buttons to ensure accessible touch targets.

• WCAG AAA contrast: Pure red (#B91C1C) white-text button and high-contrast dark toast (#1C1E21) fulfill rigorous visibility requirements.
