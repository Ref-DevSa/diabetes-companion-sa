Screen S8 “Glucose Diary” — Diabetes Companion SA

Purpose: View, record, edit, and delete glucose readings (newest first). Reserved exclusively for logged-in Users. Formatted strictly for a 360 px wide Android viewport with 16 px screen margins, 48 px high buttons/inputs, 44×44 px minimum touch targets, medical safety flags (Low & Very High), sticky "Add reading" CTA above the active Diary tab bar, and all required operational states.

State 1: Normal (5 Readings + Sticky CTA) State 2: Empty ("No readings yet") State 3: Loading (Grey Skeletons) State 4: Error ("We couldn't load your Diary") State 5: Offline (Banner + Disabled Actions) State 6: Success 1 ("High five! Reading saved.") State 7: Success 2 ("Reading updated.") State 8: Success 3 ("Reading deleted.")
